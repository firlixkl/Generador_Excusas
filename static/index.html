🎭 Excusas ML v4 · línea temporal

Paso 1 · Tu frase y los mandos

Temperatura baja → siempre el carácter más probable (coherente, aburrido). Alta → aplana las probabilidades (creativo, locura). Top-k descarta todo salvo los k favoritos.

Paso 2 · Tokenización para el clasificador

La frase se pasa a minúsculas y se parte en palabras; cada palabra es un número. Si no está en el vocabulario: UNK (el modelo no la conoce).

—

Paso 3 · Clasificador multi-label

Una probabilidad independiente por etiqueta (sigmoide). La línea amarilla es el umbral. Puedes forzar etiquetas a mano.

—

Paso 4 · Montaje del prompt y conversión a números

El generador solo ve esta cadena, carácter a carácter. Cada carácter es un id de su vocabulario.

—

Paso 5 · Generación autorregresiva, carácter a carácter

En cada paso el modelo da una probabilidad a cada carácter posible, se aplica temperatura/top-k, se sortea uno y se añade al texto para el siguiente paso.

—

🕘 Línea temporal: arrastra para volver a cualquier paso. Todos los paneles de abajo (probabilidades, atención, capas, embeddings) muestran exactamente lo que el modelo vio y decidió en ese paso. El texto en gris es lo que todavía no había escrito.

🔦 Atención: dónde mira el modelo

Para el carácter que está prediciendo, cada cabeza reparte su atención entre los caracteres anteriores. Más azul = más atención.

Historial (cada fila = un paso; columnas = posición en el texto; línea amarilla = fin del prompt)

🧱 Capas: el vector del último carácter

Vector de 128 números (resumido en 32 casillas) tras cada etapa: embedding → suma con posición → bloques → capa final. Naranja = positivo, azul = negativo.

🗺 Mapa de embeddings

Cada carácter es un punto (proyección 2D). Naranja = carácter de entrada actual · verde = carácter elegido. Tras entrenar, caracteres parecidos se agrupan.
